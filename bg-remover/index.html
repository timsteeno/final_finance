About Open BG Remover

A free, open-source replacement for remove.bg. All processing happens locally in your browser using ONNX Runtime Web; images are never uploaded.

  • Fast — U²-Netp (Apache-2.0), 4.6 MB
  • Balanced — ISNet / DIS, 8-bit, 44 MB
  • Best — ISNet / DIS, fp16, 88 MB

Models download once and are cached for offline use. See licenses/ and the README for details.

Shortcuts: Ctrl+V paste · E erase · R restore · H move · [/] brush size · C compare · O original · 0 fit · Ctrl+Z undo · Ctrl+S download
